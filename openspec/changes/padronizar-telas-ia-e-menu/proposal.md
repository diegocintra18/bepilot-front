## Why

As telas de uso de IA e a navegação relacionadas estão com padrões visuais/UX inconsistentes entre si, dificultando o reconhecimento do produto e reduzindo a clareza do fluxo para o usuário. Além disso, o menu de navegação não oferece os links das telas de IA de forma completa e o item de “planos de estudos” está sem ícone.

Esta mudança padroniza a experiência visual e melhora a acessibilidade/consistência da navegação, reduzindo atrito e aumentando a encontrabilidade das funcionalidades.

## What Changes

- Padronizar a interface das telas de uso de IA seguindo o mesmo padrão visual do projeto (com componentes e estilos consistentes).
- Incluir/atualizar links no menu de navegação para acessar as telas de uso de IA.
- Corrigir o item do menu “planos de estudos” para exibir um ícone.

## Capabilities

### New Capabilities
- `telas-ia-e-menu-padronizados`: Garantir que as telas de uso de IA sigam o padrão visual do projeto e que a navegação (menu) tenha links corretos para acessá-las, incluindo correções visuais no item “planos de estudos”.

### Modified Capabilities
- (none)

## Impact

- Front-end: componentes de layout e navegação (menu), telas de uso de IA e seus estilos.
- Manutenção: padronização reduz divergência futura entre telas e melhora consistência de UX.
